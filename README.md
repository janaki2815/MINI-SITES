# 🚀 MINI-SITES — A Collection of Mini Projects

A collection of interactive web projects built to practice frontend development, explore UI/UX design, and create useful applications.

This repository brings together three projects: a **Number Guessing Game**, an **Expense Tracker**, and my interactive personal portfolio, **JAX\***.

## 📌 Projects

### 🎯 1. Number Guessing Game

A simple interactive game where players try to guess a hidden number.

**Highlights**
- Interactive number-guessing gameplay
- Immediate feedback while playing
- A lightweight browser-based experience

**Technology:** HTML, CSS, JavaScript

**Source code:** [`MINI-GAME/`](./MINI-GAME/)

### 💰 2. Expense Tracker

A web application for recording and managing personal expenses.

**Highlights**
- Add expenses with a name, amount, and category
- View recorded expenses
- Delete expenses when needed
- View expense totals and filter by category
- Save expense data in browser local storage

**Technology:** HTML, CSS, JavaScript

**Source code:** [`expense-tracker/`](./expense-tracker/)

### ✨ 3. JAX* — Personal Portfolio

An interactive portfolio showcasing my identity as a full-stack developer and applied AI enthusiast.

The portfolio features a distinctive red visual theme, hand-drawn character artwork, playful interface elements, and interactive navigation.

**Highlights**
- Interactive landing page and reveal experience
- About Me and personal profile sections
- Project exploration interface
- Interactive visual elements and animations
- Responsive layouts for different screen sizes

**Technology:** React, TypeScript, Vite, CSS

**Source code:** [`jax/`](./jax/)

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git, if you want to clone the repository
- Node.js and npm to run the JAX* portfolio

### 1. Clone the repository

```bash
git clone https://github.com/janaki2815/MINI-SITES.git
cd MINI-SITES
```

### 2. Run the Mini Apps home page

Open the root `index.html` in your browser, or use the Live Server extension in VS Code or Cursor.

From the home page, you can open the Number Guessing Game and Expense Tracker.

### 3. Run the JAX* Portfolio

Open a terminal in the repository root and run:

```bash
cd jax
npm install
npm run dev
```

Open the local URL printed in the terminal to explore the portfolio.

### 4. Build the portfolio for production

From inside the `jax/` directory, run:

```bash
npm run build
```

Vite generates the production build in the `jax/dist/` directory.
